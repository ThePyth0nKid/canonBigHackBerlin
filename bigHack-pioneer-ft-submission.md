## Fastino side-challenge confirmation text (submission form)

```
Built a domain-specialised NER model for the Qontext/Inazuma corpus by
fine-tuning the open GLiNER architecture that Pioneer hosts.

Pipeline (all reproducible in repo):
1. Tri-model gold test set (Pioneer GLiNER-2 + Gemini 2.5-flash +
   Claude Opus consensus, disagreements resolved with reasoning trail).
2. Synthetic training data generated by Gemini 2.5-flash with strict
   structured-output validation (819 examples, 97.6% pass rate).
3. Templated augmentation for hard ID labels (CUSTOMER_ID,
   EMPLOYEE_ID, TICKET_ID, THREAD_ID) using disjoint train/test
   ID pools to prevent leakage.
4. Fine-tune on Modal A10G in 197 seconds (3 epochs, gliner_large-v2.1).
5. Eval against Pioneer zero-shot AND Gemini 2.5-flash frontier on
   the same 77-example gold set.
6. Live integration into Canon's signing pipeline; every fact carries
   `extractorModel: gliner-ft-canon-inazuma-v1` for full provenance.

Results: macro-F1 [TBD vs TBD vs TBD]. Inference latency ~400ms via
Modal endpoint. Plan + scripts public in repo.

Pioneer is the production extractor in Canon's live ingest loop AND
the zero-shot baseline our fine-tune is measured against. The full
sprint plan lives in bigHack/pioneer-gliner-finetune/.
```
